# SQL query collection
`database/sample_queries.sql` contains the 20 required demonstrations (SELECT, INSERT, UPDATE, DELETE, INNER/LEFT/multi-table JOIN, GROUP BY, HAVING, ORDER BY, aggregates, subquery, EXISTS, full-text, view, transaction, function, trigger, index-supported query with EXPLAIN, vector similarity) plus six analytics queries (status counts, most searched topics, most retrieved papers, daily search/question volume, evidence per section, stale embeddings). Run: `psql "$DATABASE_URL" -f database/sample_queries.sql` after `npm run seed`. Queries 6, 18 and 20 and analytics A3/A5 are most meaningful after embeddings exist.
